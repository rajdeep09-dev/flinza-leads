2. **Still To Be Scraped Timeout Queue (`1,634,710` stores)**: Stores that timed out during the aggressive 3-second rapid cluster scan, deduplicated and formatted for secondary re-scraping with higher timeout limits or residential proxies.

## 🔁 Re-Crawling the Timeout Queue (Quickstart)

To re-harvest the 1.63M timeout stores with a relaxed 10-second timeout:

```python
import pandas as pd
import httpx

# Load Part 1 or Part 2
df = pd.read_csv("still_to_be_scraped/still_to_be_scraped_part1.csv")

# Extract domains
domains = df["Domain"].dropna().unique()
print(f"Loaded {len(domains):,} domains for retry crawl...")

# Re-crawl with 10s timeout tolerance
client = httpx.Client(timeout=10.0, follow_redirects=True)
for domain in domains[:10]:
    try:
        resp = client.get(f"https://{domain}")
        print(f"{domain} -> HTTP {resp.status_code}")
    except Exception as e:
        print(f"{domain} -> {e}")
```
